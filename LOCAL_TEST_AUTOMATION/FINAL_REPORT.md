# THE LAST MARINE — 로컬 테스트 자동화 통합 결과

판정: **PARTIAL**.

로컬 실행기와 재사용 시나리오를 구현했다.
실제 게임에서 입력 묶음, 메뉴 판정, W/R 소비와 실패 중단을 확인했다.
네이티브 Q 입력 뒤 ACCESS_VIOLATION이 발생했다.
현재 네이티브 명령 후보는 일반 회귀 실행에서 제외한다.
오류의 정확한 내부 원인은 아직 UNCONFIRMED다.

## 구현과 보존

기존 Python 3.14, Windows 입력 API와 한국어 OCR을 재사용했다.
추가 설치는 수행하지 않았다.
JSON 시나리오가 여러 입력과 상태 확인을 한 프로세스에서 처리한다.
창 활성화, 프로세스 경로와 원본 해시를 확인한다.
클릭 위치에 다른 창이 있으면 중단한다.
외부 입력, 전경 손실, 대상 창 소실과 입력 전달 실패에서도 중단한다.
종료 시 눌린 입력을 해제한다.
외부 입력의 키 값은 기록하지 않는다.

원래 게임 소스와 SCX는 변경하지 않았다.
SCX 빌드와 기존 36개 게임 상태 검사를 반복하지 않았다.
기존 WO 증거도 유지했다.
클라이언트 파일, DLL과 게임 메모리는 변경하지 않았다.
검사는 승인된 로컬 시험 맵에서 진행했다.

## 실제 게임 결과

게임 환경은 Remastered 1.23.10.13515, koKR, 64비트다.
측정한 창 모드의 클라이언트 캡처는 1280×960이다.
이전 전체 화면 캡처는 2048×1152다.
이 두 캡처만으로 해상도 회귀 검증을 완료하지 않았다.

네이티브 명령 실행은 2 PASS / 1 FAIL / 1 NOT RUN이다.

## 성능 비교

동일한 로컬 게임에서 F10 메뉴 열기와 Escape 닫기를 비교했다.
각 방식의 표본은 1회다.
메뉴 측정은 코드 사본 저장과 시작 시 입력 유지 검사를 추가하기 전 버전이다.
마지막 보완 버전의 실게임 성능 재측정은 NOT RUN이다.

| 측정 항목 | Computer Use | 로컬 실행기 |
|---|---:|---:|
| 관측한 시나리오 구간 | 16.770초 | 0.557초 |
| AI 측 실행 요청 | 2회 | 1회 |
| 화면 캡처 | 2회 | 2회 |
| 입력 전달 실패 | 0회 | 0회 |
| 재시도 | 0회 | 0회 |
| 메뉴 전환 판정 | 2개 화면 수동 확인 | 2개 실제 패널 상태 확인 |

실행 요청 수는 이 짧은 시나리오에서 50% 감소했다.
캡처 수는 감소하지 않았다.
관측 구간의 시간 차이는 96.7%다.
이 수치를 전체 테스트의 속도 향상으로 일반화하지 않는다.

Computer Use 시간에는 두 호출 사이의 조정 시간이 포함된다.
로컬 시간에는 Python 시작과 도구 전송 시간이 포함되지 않는다.
따라서 두 수치는 동일한 전체 도구 지연 측정값이 아니다.
게임 반응 시간만 분리한 개선율도 아니다.
AI 추론 시간은 별도로 측정하지 못했다.

Computer Use 내부 입력 시간 합계는 1.542초다.
화면·상태 반환 시간 합계는 2.600초다.
두 값의 합계는 4.142초다.
나머지 시간은 조정, 전송, 스케줄링과 추론이 섞여 있다.
로컬 입력 시간은 0.354초다.
로컬 캡처 시간은 0.120초다.
로컬 메뉴 판정은 OCR 없이 실제 파란 패널 비율을 사용했다.

전체 W/R 검증의 동등 성능 비교는 NOT RUN이다.
OCR 오인식과 네이티브 Q 오류 때문에 같은 전체 시나리오를 완료하지 못했다.
개발 중 실패한 시도도 runs 폴더에 보존했다.
성공한 메뉴 측정만으로 전체 신뢰성이 동등하다고 판정하지 않는다.

## 자동 검사와 롤백

실행기 자동 검사는 **20 PASS / 0 FAIL**이다.
잘못된 상태의 거짓 PASS, 검은 화면, 실패 후 입력, 잘못된 경로와 입력 범위를 검사했다.
실제 외부 사용자 입력 주입 시험은 NOT RUN이다.
실게임의 전경 손실과 대상 소실 중단은 확인했다.
마지막 입력 보호 보완 뒤 실게임 재검사는 화면 제어 중단으로 NOT RUN이다.

별도 work 복사본에 ROLLBACK.sh를 실행했다.
복사본의 실행기 파일 5개가 제거됐다.
증거 표식은 보존됐다.
원래 게임 소스, SCX와 실행 파일의 해시는 일치했다.
활성 실행기는 그대로 유지했다.

정확한 명령, 입력, 리터럴 출력과 종료 코드는 VERIFICATION.txt에 있다.
BASELINE, MODIFIED, ROLLBACK, RESTORED의 종료 코드는 모두 0이다.
