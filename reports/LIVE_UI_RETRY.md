# 실제 게임 재시도 결과

기준일: 2026-11-03. 상태: PARTIAL.
기존 Escape 중지 응답은 이번 세션에서 해제됐다.
기록은 Computer Use 화면 관찰에 근거한다. 자동 시험 결과와 구분한다.

## 환경과 진입

StarCraft: Remastered 1.23.10.13515에서 실행했다.
로컬 프로필 tlmpoc를 사용했다. 게임 유형은 유즈맵 설정이다.
SKILL_POC.scx를 시작하고 Last Marine 선택과 이동을 확인했다.
초기 체력은 30/40이다. HUD는 Q 0s, W unlocked 0s, kits 3을 표시했다.
기본 섬멸전 진입은 종료한 뒤 유즈맵 설정으로 다시 진입했다.
게임 속도 설정과 정확한 경과시간은 별도로 측정하지 않았다.

## 관찰 결과

|항목|입력과 화면 결과|판정|
|---|---|---|
|창 조작|해병 선택, 우클릭 이동, F10 메뉴 열기, 버튼으로 게임 복귀|PASS|
|Q 발동|q 반복 입력 뒤 `Q active | armor +2 | movement cancels` 표시|PASS: 발동 메시지|
|Q 종료|추가 이동 명령 전 `Q ended | base armor restored`와 Q 8s 표시|PASS: 종료 메시지|
|Q 실제 방어력|능력치 툴팁과 피격 피해량은 검사하지 않음|UNVERIFIED|
|W 치료|F8 반복 입력 뒤 시전 메시지, 체력 30/40 → 40/40|PASS: 회복 결과|
|W 자원|치료 뒤 HUD `W/F8 first aid unlocked 29s | kits 2` 표시|PASS: 1개 소비와 쿨타임|
|W 재사용|F8 재입력 뒤 `BLOCKED: W cooldown` 표시. 체력 40/40과 kits 2 유지|PASS|
|F9 초기화|반복 입력 뒤 CHECKPOINT 메시지, Q 0s, W 0s, kits 3 표시|PARTIAL|
|F9 해병 유지|초기 미니맵 점이 이후 관찰에서 사라짐. 해병의 지속 유지와 체력 복원은 미확인|UNCONFIRMED: 재현 필요|

초기 단발 Q/W/F7/F8 입력에서는 발동 화면을 확인하지 못했다.
반복 입력에서 Q와 F8이 감지됐다. 입력 누락 원인은 아직 확정하지 않았다.
한 번의 누름에 대한 안정성과 입력 지연은 통과로 판정하지 않는다.
Q 방어력 +2는 화면 메시지의 주장이다. 실제 수치 검증과 동일하지 않다.
Q 종료는 다음 이동 명령 전에 관찰했다. 이동 중단 시험으로 합산하지 않는다.
W 회복은 최대 체력 제한에 도달했다. 25 전체 회복량 검증은 별도로 필요하다.
F9 반복 입력은 개별 복원 횟수의 증거가 아니다.
마지막 화면은 F10 메뉴가 열린 일시정지 상태다.

## 남은 검사

Q 이동 중단과 피격 피해량을 검사한다.
W 이동·피해 중단과 정확한 시전시간을 검사한다.
단발 입력과 F7 대체 입력을 재검사한다.
F9 해병 유지 문제를 단발 입력으로 재현한다.
COLLAPSE_90S_POC 정상 진행, 스킵, 카메라와 음향을 검사한다.
실게임 사망 복구와 전체 체크포인트 검사는 NOT RUN이다.
WO-04와 Phase 1 전체 완료 게이트는 아직 충족하지 않았다.
