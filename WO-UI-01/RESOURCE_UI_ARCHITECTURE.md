# WO-UI-01 자원 아키텍처

상태: 소비 로직 PoC 구현. 최종 그래픽 UI는 BLOCKED.
실제 제작 경로는 기존 scmJS 0.8.5와 TrigScript 4.1.0이다.

## 상태 소유권

|상태|역할|변경 주체|
|---|---|---|
|kits|응급처치 키트의 기준 수량|W 완료와 체크포인트|
|explosives|전술 폭약의 기준 수량|R 시험 설치 완료와 체크포인트|
|wReady / rReady|각 스킬의 다음 사용 시각|각 스킬 완료와 체크포인트|
|wUntil / rUntil|현재 시전 종료 시각|입력, 중단, 완료|
|mode|0 생존, 1 지휘|전환 시험 C|
|campaignKits / campaignExplosives|전환 직전 수량 복사본|생존→지휘 전환|
|미네랄 / 가스|생존에서는 진단용 출력. 지휘에서는 생산 자원|표시 어댑터 또는 RTS 경제|

생존 수량의 기준은 kits와 explosives다. 상단 수량을 읽어서 소비 여부를 결정하지 않는다.
생존 모드는 매 프레임 기준 수량을 Set Resources로 복사한다.
이 숫자 투영은 최종 UI가 아니다. 남아 있는 광물·가스 그림은 실패 항목이다.

## W 계약

해금·생존·주인공·상호 배제·키트·쿨타임·정지 조건을 검사한다.
3초 시전 뒤 체력 25 회복을 적용한다. 체력은 최대값을 넘지 않는다.
정상 완료 시 kits를 한 번 감소시킨다. 이후 wReady를 40초 뒤로 설정한다.
이동·좌표 변경·5 이상 피해·강제 제어는 시전을 취소한다.
중단은 키트와 쿨타임을 소비하지 않는다.
Q의 기존 효과·종료 계약은 유지한다. R 시전 중에도 공통 시전 잠금을 적용한다.

## R 시험 계약

R 또는 L 입력은 정지 상태에서 3초 설치 시험을 시작한다.
설치가 완료되면 explosives를 한 번 감소시킨다. rReady는 60초 뒤가 된다.
시전 중 자원은 예약·차감하지 않는다.
이동·좌표 변경·사망·강제 제어는 설치를 취소한다. 중단 시 차감과 쿨타임은 없다.
보유량 0은 재사용을 차단한다. 음수 수량과 중복 설치를 방지한다.
R 시험은 설치 횟수만 기록한다. 폭발·범위 피해·아군 피해·장애물 파괴는 미구현이다.
지형·설치 거리·안전거리·기폭 순서는 최종 R 작업에서 검증한다.

## 체크포인트

F9는 kits=3, explosives=2와 모든 스킬 쿨타임을 복원한다.
현재 시전과 R 시험 설치 횟수를 초기화한다.
살아 있는 해병은 유지하고 안전 구역으로 이동한다.
사망 복구는 유닛 생성 후 다음 프레임에 참조를 다시 찾는다.
기존 원본 소스와 맵은 보존했다. 이 변경은 새 UI 시험 소스에만 적용했다.
현재 체크포인트는 고정 시험값이다. 전체 캠페인 저장값의 직렬화는 미구현이다.

## M01~M05 표시 정책

M01~M03은 생존 모드를 사용한다. 생산과 자동 채취는 이 모드에서 활성화하지 않는다.
M04는 소모품 스냅샷을 먼저 만든다. 이후 표시 어댑터의 소유권을 지휘 모드로 넘긴다.
M05의 미네랄·가스는 생산 자원이다. 소모품은 CampaignState.inventory에 별도로 보존한다.
두 상태는 같은 변수에 저장하지 않는다.
UI PoC의 C는 500 미네랄·250 가스로 전환하는 시험 명령이다.
이후 생존 어댑터는 생산 자원을 덮어쓰지 않는다. 생존 스킬 입력도 차단한다.
실제 생산·건설·전투 지휘는 이 시험 맵의 구현 범위에 포함하지 않았다.
다음 맵으로 보낼 때 manual code payload에 medicalKits와 explosives를 별도 필드로 배정한다.
버전·범위·체크값을 검사한 후에만 복원한다. 코드 인코더·입력 UI는 후속 작업이다.
일반 Death Counter가 맵 사이에 자동 전달된다고 가정하지 않는다.

## 표시와 툴팁

현재 한국어 명칭과 소비 안내는 ui.lines의 진단 텍스트다.
실제 W/R 버튼과 네이티브 툴팁은 생성·변경하지 않았다.
최종 W 툴팁은 `응급처치 키트 1개 / 치료 성공 시 소비`를 표시해야 한다.
최종 R 툴팁은 `전술 폭약 1개 / 설치 성공 시 소비`를 표시해야 한다.
현재 화면은 의료 키트·폭약 그림을 제공하지 않는다. 미네랄·가스 그림도 남는다.
실게임에서 텍스트 중복과 전환 직후 이전 수량 잔류를 관찰했다.
따라서 현재 패널을 동등한 직관성의 대안으로 승인하지 않는다.

## 시험 조작

1. 유즈맵 설정으로 RESOURCE_UI_POC.scx를 시작한다.
2. Q/F7로 기존 방어 자세를 검사한다.
3. W/F8로 지혈을 검사한다.
4. R/L로 설치 소비 시험을 실행한다.
5. D로 시험 체력을 10으로 설정한다.
6. F9로 고정 체크포인트를 복원한다.
7. C로 RTS 자원 분리 시험을 실행한다.

F4~F6는 고정 컴파일러가 지원하지 않아 채택하지 않았다.
단발 자동 입력 누락이 남아 있어 실게임 일부 검사는 반복 입력으로 수행했다.
