# WO-UI-01 최종 작업 보고서

판정: **BLOCKED**.
자원 소비 시험 맵과 기술 조사를 작성했다. 필수 그래픽 UI의 완료 게이트는 미충족이다.

## 확인한 결과

실게임에서 W 성공 뒤 상단 A가 3→2로 감소했다.
R 시험 설치 뒤 상단 B가 2→1로 감소했다.
복원 후 R을 두 번 설치하면 B가 0이 됐다. 이후 입력은 부족 사유로 차단됐다.
F9는 상단 3/2와 살아 있는 해병을 복원했다. 이전 텍스트 수량이 잠시 남았다.
RTS 전환 시험은 생산 자원 500/250을 표시했다.
한국어 이름은 읽을 수 있었다. 그러나 상단의 원래 그림은 그대로 남았다.
진단 텍스트의 중복·소실·갱신 지연도 관찰했다.

## 완료 판정을 막는 항목

군용 의료 키트 그림과 군용 폭약 그림은 표시되지 않았다.
상단 슬롯의 한국어 명칭도 구현되지 않았다.
실제 스킬 버튼과 네이티브 툴팁은 미구현이다.
다중 해상도·UI 배율, W 부족과 중단의 실게임 검사는 남아 있다.
맵 전용의 동등 그래픽 대안은 검증·승인되지 않았다.
따라서 숫자·채팅 이름만으로 GO 또는 CONDITIONAL GO를 부여하지 않는다.

기존 기준선은 30건 통과했다. 새 PoC는 26건 통과했다.
복원한 별도 복사본은 기존 회귀 검사 15건을 통과했다.
복원 검사는 새 수정 소스를 덮어쓰지 않았다. 원본과 수정본을 각각 보존했다.
실제 게임 결과와 화면 해시는 TEST_RESULTS와 VERIFICATION을 기준으로 확인한다.
R은 설치 소비만 구현했다. 전투 효과와 최종 스킬 완료를 주장하지 않는다.

## 후속 결정

문서화된 맵 전용 그래픽 UI 경로 또는 검증 가능한 새 도구가 다음 기술 의존성이다.
클라이언트 자산 방식은 별도 제안으로 유지한다. 사용자 승인 없이 필수화하지 않는다.
독립 패널을 제안할 때 그림·한국어·수량·기존 아이콘 혼동 해결을 함께 검증해야 한다.
현재 진단 패널은 승인할 완성 대안이 아니다.
Phase 1 전체와 WO-UI-01 기능 완료 판정은 계속 열어 둔다.
