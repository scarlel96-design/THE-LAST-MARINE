## 통과로 처리하지 않은 항목

텍스트의 소비 안내는 네이티브 스킬 버튼 툴팁이 아니다.
R 소비 시험은 최종 폭약 전투 효과가 아니다.
가설적인 클라이언트 모드 경로는 실제 호환성 검증이 아니다.
동등 대안의 승인 없이 CONDITIONAL GO를 부여하지 않는다.
