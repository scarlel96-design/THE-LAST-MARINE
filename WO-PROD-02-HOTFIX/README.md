# M01 시작 수정판

사용자가 이전 M01에서 해병을 선택할 수 없고, 해병이 아군 시설을 공격하며, 화면도 이동하지 않는 현상을 보고했다. 원본 SCX를 다시 읽어 P1과 해병 소유권이 이미 올바른 것을 확인했다. 기존 SCX에 시작 동맹 트리거는 없었다. 실게임 증상의 정확한 원인은 확정하지 않았다.

- 시작 시 테란과 저그 내부의 상호 동맹을 일반 트리거로 지정한다. 테란 주둔 시설은 P3에 둔다.
- 시작할 때 P1 해병을 한 번 선택한다. 자동 화면 이동은 시작, 붕괴, 스킵, 체크포인트 복원에서 제거했다.
- J를 눌러 해병을 선택하고 위치를 찾는다. 그 뒤 화면 이동은 플레이어가 조작한다.
- 기존 지형, 배치, 방어선 진행, 구조, 장비, 계승을 유지했다.

## 다시 확인

1. `M01_NORTH_RIDGE_START_FIX.scx`를 스타크래프트 문서의 `Maps/TLM_Phase1`에 복사한다.
2. 새 파일을 선택하고 **맵 설정 사용(Use Map Settings)**으로 시작한다.
3. 치트 없이 시작 해병을 클릭한다. 화면 가장자리와 미니맵으로 화면을 이동한다. 주둔 건물이 공격 대상이 아닌지 확인한다.
4. J를 한 번 누른다. 카메라가 해병으로 이동한 뒤 다시 화면을 움직인다.

증상이 계속되면 `M01_CONTROL_CHECK.scx`로 같은 시작 구역을 비교한다. 비교 맵에는 일반 동맹과 안내 텍스트 트리거만 있다. 미션 진행과 키 입력 스크립트는 없다. 비교 맵에서만 조작이 정상이라면, 다음 점검은 본편 런타임과 입력 처리를 분리해 진행한다.

소스 시뮬레이션 34개 통과. SCX 3개를 다시 열어 소유권, 동맹, 지형, 배치를 비교했다. 수정본의 마우스 선택, 적대 여부, 화면 스크롤은 실게임 **NOT RUN**이다. 현재 테스트 폴더의 기존 파일은 그대로 뒀다.
