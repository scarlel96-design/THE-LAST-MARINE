배드랜드의 실제 타일을 사용했다. 두 고도와 물·절벽 전이를 배치했다. 미니타일 통행 조건과 건물 외곽 여유 폭을 검사했다. 기존 12개 경로를 모두 유지했다. 추격, 구조, 우회용 경로를 추가해 25개를 검사했다. 네이티브 시야 판정과 실제 유닛 길 찾기는 **NOT RUN**이다.

### 연출과 진행

1. 초소 경보 뒤 저글링을 초소 방향과 외곽 벙커 방향으로 나눈다. 외곽 방어조에는 방어 명령을 준다.
2. 외곽이 돌파되면 남은 저글링이 내부로 추격한다. 경계조는 내부 방어선으로 후퇴한다.
3. 내부 압박 뒤 방어조는 착륙장으로 이동한다. 베일·렌·모로와 구조 인원은 실제 대피 구역에 도착해야 기록된다.
4. 수송선은 이동 후 추락한다. 탄약고 피격과 대피 조건이 충족되면 시설을 파괴하고 폭발음을 재생한다.
5. 장면 카메라는 최대 1초 뒤 복귀한다. 조사 또는 Q/W 입력으로 일찍 되돌릴 수 있다. Escape 스킵은 선택 보상이나 구조 기록을 지급하지 않는다.

기존 진행 번호, 장비·보급 규칙, 체크포인트, 결과 계산을 유지했다. 원본 M01 회귀 29개와 이번 연출 검사 3개가 통과했다. 브리핑 4줄, 무전 50줄이다.

## M02 — 동부 군수기지 17-B

| 구간 | 구현 |
|---|---|

| 배전·정찰 | 배전기 내구도를 복구하고 양쪽 벙커를 플레이어에게 넘긴다. 저그 정찰대를 제거해야 창고가 열린다. |

| 1·2차 방어 | 서문 접근 후 배수로 방향에서 공격한다. 배수로를 봉쇄하면 2차 적 진입 위치가 바뀐다. 감시시설과 계승 경보는 준비 시간을 늘린다. |

| 3차 방어 | 북문 저글링과 배전기 우회 히드라리스크를 동시에 처리한다. 배전기가 파괴되면 방어 실패로 종료한다. |
| 전초 반격·종료 | 부화장과 경비를 제거하고 지하 연결망 좌표를 기록한다. 북쪽 진입로에서 M03 코드를 확정한다. |

적 배치는 정찰 4, 방어 8·7·14, 반격 10으로 고정했다. 부화장 1개는 별도 목표다. 대기 시간이나 F9로 적과 보급이 다시 생성되지 않는다. 해병은 마지막 유효 구역으로 복구된다. 배전기가 파괴된 뒤에는 진행을 되감지 않는다.

Q/F7과 W/F8은 키 입력 경로를 유지했다. E는 이동으로 해제되는 전술 연사이며 자원 소모 없이 쿨타임을 적용한다. R은 M03까지 잠겨 있다. E의 게임 내 공격 속도와 조작감은 **NOT RUN**이다.

일반 맵에는 브리핑 3줄이 있다. 계승 맵은 인물, 경로와 장비 결과 2줄을 추가한다. 런타임 무전은 31줄이다.

## 계승

- **M01 → M02:** `TLM1-2:A:B:C:CHECK`와 검사 규칙을 그대로 사용했다. 기존 코덱 파일도 바이트 변경이 없다.
- **계승 시작:** 베일 생존은 경고 대사를 바꾼다. 렌 생존은 부품을 제공한다. 모로 생존과 구조 주민은 피난소 보급에 반영한다. 구조 군인은 집결소에 합류한다.
- **장비와 정보:** 소총·전투복·숙련·소모품을 시작값으로 적용한다. 내열 라이닝은 과부하 피해를 줄인다. 회수한 주파수 자료는 중계소 대사를 바꾼다.
- **잘못된 코드:** 빌더는 파일을 쓰기 전에 버전, 범위와 검사값을 확인한다. 잘못된 코드를 새 시작으로 처리하지 않는다.
- **M02 → M03:** `TLM1-3:A:B:C:D:E:CHECK`를 출력한다. M01 인물·선택·기록, 현재 장비·보급, M02 방어·복구·반격·선택 기록을 구분한다. 최소 완료 경로는 `TLM1-3:0:480:16680:0:7:9619`다.

독립 SCX 사이에 자동 공유는 없다. 계승은 검증한 코드를 별도 맵에 넣는 방식이다. 인게임 입력 UI와 M03 본편은 미구현이다.
