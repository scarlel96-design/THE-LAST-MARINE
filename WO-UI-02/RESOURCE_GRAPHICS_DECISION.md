# WO-UI-02 자원 명칭 결정 자료

현재 판정: **PARTIAL / 이름 바인딩 미검증**.
최신 변경 지시는 미네랄·가스 그림 교체 요구사항을 해제했다.
기존 그림은 현재 완료 판정의 실패 사유가 아니다.
필수 명칭은 `응급처치 키트`, `전술 폭약`이다.
이 명칭은 해당 상단 수량과 명확하게 연결되어야 한다.

## 경로 비교

|경로|근거|현재 결과|클라이언트·배포|
|---|---|---|---|
|A. 표준 SCX|문자열, 유닛 이름, 자원 트리거|조사한 표준 필드에서 상단 자원 제목 바인딩을 확보하지 못함|맵 한 개|
|B. 맵 전용 EUD|기존 stat_txt 포인터와 문자열 오프셋 변경|실게임에서 포인터와 1539개 테이블 관찰. 이름 교체는 아직 미실행|맵 한 개 목표. 현재 우선 조사 경로|
|B. 독립 텍스트 표시|기존 ui.lines 실행 증거|중복·F9 이전 값 잔류·소실 관찰. 동등 대안 승인 없음|설치 추가 없음. 현재 완료안에서 제외|
|C. 자산·UI 플러그인|Animosity와 samase_plugin 제작자 자료|조사만 수행. 현재 클라이언트 실행과 호환성 NOT RUN|추가 설치·버전 관리·배포 검토 필요|

A 경로의 공개 필드 부재는 전체 EUD 경로의 부재를 증명하지 않는다.
B 경로는 문자열 할당과 상단 표시의 연결을 각각 검사해야 한다.
이 단계에서 A/B 전체의 구현 중단 판정을 확정하지 않는다.
C 경로는 채택하지 않았다.
별도 클라이언트와 외부 DLL을 설치하지 않았다.
게임 원본 파일은 변경하지 않았다.

## 문자열 처리 설계

실게임 진단값은 다음과 같다.

`count=1539 first=3080 ptr=421021280 offsets=true tail=true ready=false`

기존 편집기의 1547/1551개 테이블과 실행 중 테이블이 달랐다.
1539개 분기를 추가한 SCX는 호스트에서 생성됐지만 실게임 검사는 아직 없다.
현재 소스는 1539/1547/1551개 구조를 후보로 처리한다.
63800~64864 영역이 비어 있는지 검사한다.
첫 문자열의 복사 길이를 64바이트로 제한한다.
두 번째 오프셋이 이 범위에 있는지 검사하도록 수정했다.
원래 첫 문자열을 보존한 뒤 새 버튼 문자열 두 개를 추가한다.
796/797은 기존 테이블에서 자원 관련 문자열의 후보 ID다.
상단 자원 UI가 이 ID를 사용하는지는 아직 확인하지 않았다.
이 ID 변경을 실제 상단 제목 변경으로 보고하지 않는다.
정적 문자열 표의 별칭과 정렬 가정도 추가 검토가 필요하다.
전체 한국어 현지화 보존은 아직 미검증이다.

eudplib은 stat_txt 문자열 수정 구현을 제공한다.
UTF-8 표시 규약과 포인터 접근을 참고했다.
[tblprint.py](https://github.com/armoha/eudplib/blob/979f2fb4e8ffa4ec62e5872bddc4c0b36ae006cf/src/eudplib/string/tblprint.py)
[TrigScript UI](https://docs.scmjs.dev/trigscript-library/ui/)
[SCX 형식](https://github.com/scm-js/scm-js/blob/f4fe24e7519096c2cdd9c1af887f9340317d7af7/docs/chk-format.md)

## 생존·지휘 모드

생존 소모품의 기준값은 kits/explosives다.
생존 모드에서 ore/gas는 표시용 복사본이다.
W 성공은 키트 한 개를 소비한다.
R 설치 성공은 폭약 한 개를 소비한다.
W 중단은 키트를 소비하지 않는다.
R에는 아직 전투 피해 효과가 없다.
C 전환은 소모품을 campaignKits/campaignExplosives로 복사한다.
생산 자원은 별도의 500/250으로 전환한다.
현재 수정은 C 전환 전에 원래 자원 문자열 오프셋을 복원한다.
현재 복원 코드를 포함한 SCX 빌드는 통과했다. 문자열 복원의 실게임 검사는 NOT RUN이다.
이 스냅샷은 맵 간 영구 저장 기능이 아니다.
캠페인 상태 직렬화와 M04/M05의 최종 정책은 별도 통합 항목이다.

## 클라이언트 경로의 판단 조건

맵 전용 경로는 설치와 배포가 단순하다.
맵 전용 경로는 에뮬레이터 허용 영역과 UI 바인딩에 제약을 받는다.
클라이언트 경로는 렌더러·대화상자 계층에 접근할 수 있다.
실행 파일 버전, HD/SD 자산, 로더 의존성이 추가된다.
외부 코드의 출처와 빌드 재현성을 확인해야 한다.
호환성, 업데이트 복원, 배포 무결성, 백신 반응은 현재 미검증이다.
이 경로를 필수 구성으로 바꾸려면 사용자 승인이 필요하다.

[samase_plugin](https://github.com/neivv/samase_plugin/blob/master/src/lib.rs)
