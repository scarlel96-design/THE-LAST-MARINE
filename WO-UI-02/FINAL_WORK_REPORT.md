# WO-UI-02 통합 작업 보고

판정: **PARTIAL**. 필수 UI의 실게임 검증이 남아 있다.

## 구현과 보존

네이티브 Q/W 버튼과 대기열 입력을 별도 시험 소스에 구성했다.
요구 조건의 상대 인덱스를 572에서 6으로 수정했다.
문자열 길이 검사와 지휘 모드의 원래 자원 명칭 복원을 추가했다.
Q/W 대기열의 모든 칸을 검사하는 자동 검사 10개를 추가했다.
원래 UI01 소스와 시험 맵의 해시는 일치한다.
R은 설치 소비 시험이며 전투 피해 효과는 미구현이다.
통합 작업 패키지 규칙을 AGENTS.md에 저장했다.

## 검증

현재 상태·대기열 검사는 36 PASS / 0 FAIL이다.
현재 SCX는 494967바이트다. 생성 후 맵을 재열었다.
롤백은 별도 복사본에 적용했다. 기준 해시와 일치했다.
복원 후 상태 검사는 26 PASS / 0 FAIL이다.
현재 수정 소스는 유지했다.
명령, 입력, 출력, 종료 코드는 VERIFICATION.txt에 있다.

게임은 HIGH, 조작 도구는 MEDIUM 권한이었다.
모든 대상의 UIAccess 값은 false였다.
창 재선택과 입력 연결 초기화 이후에도 맵 선택은 바뀌지 않았다.
현재 맵의 기능 검사는 NOT RUN이다.
UIPI 진단 근거는 LIVE_INPUT_BLOCKER.md에 있다.
