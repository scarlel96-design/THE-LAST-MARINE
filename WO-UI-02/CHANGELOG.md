# WO-UI-02 변경 이력

## 중단 전

네이티브 버튼셋, 생산 대기열 토큰, 문자열 할당 시험 소스를 분리했다.
기존 소비 로직을 F7/F8 진단 입력으로 회귀 검사했다.
실게임에서 버튼 표시와 문자열 테이블 진단을 기록했다.

## 테스트 중단 후

요구 조건 파일의 헤더 기준 오류를 수정했다.
요구 조건 종결자와 첫 문자열 길이 가드를 추가했다.
지휘 모드에서 원래 자원 문자열 오프셋을 복원하도록 수정했다.
향후 빌드 결과의 소스 추적 정보를 추가했다.
이전 보고서와 현재 미검증 소스를 구분했다.
UI01 보고서의 재실행 타임스탬프 변경을 기준 커밋의 내용으로 되돌렸다.
통합 개발 기준과 Astra 검토 자료를 저장했다.
테스트와 롤백 실행은 중단 상태를 유지했다.

## 재개 후 통합 검증

현재 소스로 494967바이트 SCX를 생성하고 재열기를 확인했다.
Q/W 대기열의 다섯 칸을 각각 검사하는 자동 검사 10개를 추가했다.
상태·대기열 검사 36개가 통과했다.
별도 복사본에 롤백을 실행하고 26개 상태 검사 통과를 확인했다.
실제 맵 선택창의 입력 전후 화면과 입력 기록을 저장했다.
현재 맵의 실게임 기능 결과는 NOT RUN으로 유지했다.
통합 작업 패키지 규칙을 AGENTS.md와 개발 지침에 반영했다.

기준 검사 26개를 baseline/WO-UI-02/state.test.ts에 보존했다.
빌더의 --tests 옵션으로 기준선 26개, 현재 36개, 복원 후 26개를 다시 검증했다.
각 실행은 종료 코드 0이었다.

## 일반 권한 재실행

기존 PID 7176의 종료를 확인했다.
-launch 인수와 UseShellExecute=false로 새 게임을 시작했다.
새 PID 66192의 MEDIUM 권한을 확인했다.
이전 관리자 권한 확인창이 남아 있어 UI 입력 재검사는 대기 중이다.
