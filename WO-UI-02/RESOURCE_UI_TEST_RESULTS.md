36개 검사는 대기열 값을 직접 주입한다.
이 검사는 버튼 콜백과 실제 키 입력을 검증하지 않는다.
메모리 가드와 한국어 문자열 변경 분기는 실게임 검증이 필요하다.
빌드 당시 검사 파일은 26개였다.
이후 검사 10개만 추가했으며 런타임 소스는 변경하지 않았다.

기존 UI01 숫자 소비 증거와 소스를 보존했다.
아이콘 교체는 현재 요구사항에서 해제됐다.
R은 설치 소비 시험이다. 전투 피해 효과는 미구현이다.
정확한 명령과 해시는 VERIFICATION.txt에 기록했다.
입력 기록은 LIVE_INPUT_RECORD.json에 기록했다.

## 다음 실게임 검증 묶음

1. NATIVE_UI_PROBE.scx를 로드한다.
2. V 진단에서 transport, ready, firstFits를 확인한다.
3. 해병의 기본 명령과 Q/W 클릭·단축키를 확인한다.
4. 선택 변경, 잠금, 쿨타임, 중단, 부족 차단을 확인한다.
5. W/R 소비와 F9 복원을 확인한다.
6. 자원 명칭과 상단 수량의 연결을 확인한다.
7. C 전환의 명칭 복원을 확인한다.
8. 한국어, 해상도, 배율, 텍스트 잔류를 확인한다.

실게임 입력의 실행 권한 차이를 확인했다. 세부 근거는 LIVE_INPUT_BLOCKER.md에 있다.

기준 검사 26개를 baseline/WO-UI-02/state.test.ts에 보존했다.
빌더의 --tests 옵션으로 기준선 26개, 현재 36개, 복원 후 26개를 다시 검증했다.
각 실행은 종료 코드 0이었다.
