# Astra UI 검토 인계 자료

상태: **PARTIAL / 현재 SCX 빌드 통과 / 실게임 입력 반영 미확인**.
이 자료는 로컬 검토용이다.
다른 대화나 외부 서비스로 전송하지 않았다.

## 확보한 근거

실게임에서 네이티브 명령창의 추가 버튼은 표시됐다.
실게임에서 W 입력의 치료 효과는 관찰되지 않았다.
요구 조건 인덱스의 파일 헤더 계산 오류를 소스에서 발견했다.
인덱스 수정 소스의 상태·대기열 검사 36개는 통과했다. 네이티브 콜백과 문자열 변경은 실게임 미검증이다.
현재 자원 문자열 테이블은 1539개다.
상단 UI의 796/797 문자열 바인딩은 아직 미확정이다.
클라이언트 설치 변경은 현재 채택하지 않았다.

## 검토할 P0

1. 요구 조건 수정 후 네이티브 클릭과 단축키 입력을 확인한다.
2. stat_txt 후보 ID와 실제 상단 자원 UI의 연결을 확인한다.
3. 문자열 별칭과 정렬 가정을 검토한다.
4. 다른 한국어 문자열의 보존을 확인한다.
5. C 전환과 F9 복원 시 명칭·수량 일치를 확인한다.

## 검토할 P1

- 버튼 잠금·쿨타임의 시각적 표현.
- 입력 누락과 선택 복원 간섭.
- 여러 해상도·UI 배율의 표시 안정성.
- F9 텍스트 잔류와 반복 출력 회귀.
- 맵 간 소모품 기록 이전.

## 재사용 검토 프롬프트

```text
THE LAST MARINE WO-UI-02 자료를 검토한다.
현재 소스와 PRE_PAUSE_EVIDENCE의 이전 결과를 구분한다.
아이콘 교체 요구사항은 해제됐다.
한국어 자원 명칭과 상단 수량의 연결은 필수다.
native-ui/main.ts, build-native-ui.mjs, DIFF.patch를 함께 검토한다.
요구 조건 인덱스 6의 상대 기준과 런타임 가드를 검토한다.
stat_txt 796/797이 상단 UI에 연결된다는 가정을 검증 대상으로 남긴다.
문자열 별칭, 길이, 정렬, 지역화 보존을 검토한다.
클라이언트 원본 수정이나 외부 DLL 설치를 전제하지 않는다.
테스트는 재개됐다. 현재 맵 선택창의 자동 입력은 선택 상태를 바꾸지 않았다.
36개 상태 검사와 복사본 롤백 26개 통과를 실게임 결과로 승격하지 않는다.
미검증 기능에는 NOT RUN을 유지한다.
실게임 증거 없이 GO 또는 전체 경로의 불가능성을 선언하지 않는다.
기존 Q/W와 W/R 소비·체크포인트 기능을 보존한다.
R은 설치 소비 시험이며 전투 스킬 완성이 아니다.
```

실게임 입력의 실행 권한 차이를 확인했다. 세부 근거는 LIVE_INPUT_BLOCKER.md에 있다.

## 실행 환경 재검사

관리자 실행 옵션을 해제하고 기존 게임을 종료했다.
새 게임 PID 66192의 MEDIUM 권한과 메인 메뉴 표시를 확인했다.
이전 실행의 관리자 권한 확인창 취소가 남아 있다.
네이티브 UI 기능 검사는 아직 NOT RUN이다.
세부 기록은 LAUNCH_PERMISSION_FIX/RESULT.md에 있다.


## 2026-11-05 로컬 실행기 통합 검증

최신 결과는 ../LOCAL_TEST_AUTOMATION/FINAL_REPORT.md에 있다.
영웅 선택, 명령창과 네이티브 Q 활성화 문구를 확인했다.

현재 네이티브 후보는 원인 확인 전 일반 회귀 실행에서 제외한다.
진단 키 W/R 소비, F9와 메뉴 자동 검사 증거를 보존했다.
상단 한국어 명칭과 네이티브 W는 미검증이다.
