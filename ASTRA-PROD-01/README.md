## 구현 결과

작전사령부, 생활구역, 두 방어선, 산업구역, 착륙장과 민간 대피로를 재배치했다.
초기 저그 72기를 제거했다. 접촉·본대·별동대·중장갑·군수시설 급습을 조건부로 생성한다.
정상 경로의 적 예산은 77기다. 반복 전투를 위한 무한 증원은 없다.
순찰조, 정비 서비스 이동, 물류 호위와 예비 기갑 이동을 추가했다.
전투 전 베일·렌·모로 대화와 선택형 기지 소개를 추가했다.
탄약고 손상과 수동 격리 폐기 경로를 연결했다. 연쇄 폭발은 실제 저장고와 사령부를 파괴한다.
기존 Q/W, 구조·보급 기록, 개량, 체크포인트와 계승 코드 v1을 재사용했다.
기존 프로토타입의 소스와 맵은 변경하지 않았다. `prototype/SHA256.json`은 보존 기준이다.

## 빌드와 검사

프로젝트 루트에서 `node tools/build-astra.mjs`를 실행한다.
작업 공간의 고정된 scmJS·TrigScript 의존성과 게임 타일 자산이 필요하다.

## 미완성·미검증

고저차는 현재 통행 제한 절벽으로 사용한다. 보행 램프와 고지 포병 진지는 미완성이다.
수목·잔해 장식과 파괴 후 지속 잔해는 미완성이다. DD2·THG2는 각각 0개다.
정비병은 서비스 경로를 이동한다. 자동 수리와 화물 적재는 구현하지 않았다.
전차는 탱크 모드다. 벙커 탑승과 공성 모드 전환 연출은 미완성이다.
중장갑 등장은 내부선 위기에 연결했다. 외곽 붕괴 이전 등장은 후속 조정 항목이다.
적 생성의 가시성은 거리 검사다. 실제 안개·생성 공간·유닛 한도 검증은 NOT RUN이다.
실제 한글 표시, 카메라, 전투 난이도, 플레이 시간과 몰입감은 NOT RUN이다.
네이티브 Q ACCESS_VIOLATION 경로는 격리했다. 네이티브 W와 상단 한글 자원 UI는 미검증이다.
M03~M05는 좌표가 있는 제작안이다. 실행 맵은 아직 없다.

## 보존과 복귀

기존 `WO-PROD-02-HOTFIX/maps/M01_NORTH_RIDGE_START_FIX.scx`를 계속 사용할 수 있다.
