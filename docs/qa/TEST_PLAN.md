# Phase 1 시험 계획

## 자동 검사

고정 버전의 공식 컴파일러로 두 빌드 변형을 검사한다.
시전·쿨타임·중단·사망·스킵·감시 복구를 독립 시험한다.
완성 SCX를 다시 읽어 크기, 주인공, 트리거, 추가 자산을 확인한다.
소스와 SCX의 SHA256을 기록한다. 같은 소스의 재빌드가 같은 결과를 만드는지 비교한다.
시뮬레이터의 유닛 피해·이동 주입은 시험 데이터다. 실제 교전 증거로 사용하지 않는다.

## 실게임

설치 버전 1.23.10.13515, UMS, Fastest에서 검사한다.
맵 선택, 로딩, 주인공 선택, 이동과 사격을 확인한다.
Q 방어력 증가와 종료·이동 중단·재사용 거절을 확인한다.
W 회복량·시전시간·차감·중단·쿨타임을 확인한다.
시작 직후와 각 단계에서 Escape를 입력한다.
정상 90초 진행에서 실제 아군·적군 이동과 시설 피해를 확인한다.
NPC 선행 사망, 주인공 이탈, 주인공 사망과 F9 재시작을 확인한다.
효과음을 청취한다. 기본 키 설정과 대체 키 설정을 각각 확인한다.
결과에 시작 시간, 맵 해시, 재현 절차, 화면 또는 영상을 첨부한다.
110초 RECOVERED를 정상 90초 PASS로 기록하지 않는다.

## 승인 게이트

실게임 필수 항목이 NOT RUN이면 WO-04와 WO-05는 완료가 아니다.
WO-06 두 맵 전달과 WO-07 수직 슬라이스가 남아 있으면 Phase 2 진입은 보류한다.
