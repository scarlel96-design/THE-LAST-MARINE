# 인물 초안

아래 인물은 창작안이다. 사용자 승인 전까지 이름과 세부 이력을 확정하지 않는다.

|인물|역할|행동과 갈등|등장|
|---|---|---|---|
|주인공, 이름 미정|일반 해병→소위|살아남기 위한 판단이 동료 생존 책임으로 바뀜|M01~M05|
|마라 베일 하사|초소 책임자|초기 후퇴를 지시, 생존 여부는 선택 분기 후보|M01|
|이언 렌 기술병|군수시설 담당|시설 기록과 복구 절차를 남김|기록·무전|
|셀린 워드 중위|정찰부대 지휘관|주인공을 의심하나 물증으로 평가를 수정|M03~M04|
|노아 케슬러 소령|심사·작전 책임자|조직 명령과 병력 생존의 충돌을 보여줌|M04~M05|

M04는 전공량으로 인격과 계급을 결정하지 않는다.
워드는 검증 자료와 본인 진술을 구분한다. 케슬러는 현장 지휘 평가를 별도로 실시한다.
