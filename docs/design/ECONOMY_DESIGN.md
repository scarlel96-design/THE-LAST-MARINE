# 보급 경제 초안

군수자재는 무기·방어복·시설의 공통 재료다. 특수부품은 고급 복구에 사용한다.
키트와 폭약은 소모품이다. 같은 상자 ID는 한 번만 획득한다.
선택 보급품을 얻지 않아도 필수 목표의 최소 장비를 확보한다.
필수 시설 앞에는 부족한 필수 재료만 보충하는 대체 경로를 둔다.
폭약 필수 목표에는 1개 이상의 보장 폭약을 둔다. 경로 재진입으로 무한 지급하지 않는다.
체크포인트는 획득 플래그와 소비 후 재고를 함께 복원한다.
재시작은 해당 체크포인트 이후의 전공·보상·적 상태를 동일하게 되돌린다.
개량 가격과 총 공급량은 아직 확정하지 않았다. WO-18 전투 측정 전에는 숫자를 고정하지 않는다.
현재 PoC에는 키트 3개만 구현했다. F9 재시작의 3개 복구는 시험용 계약이다.
