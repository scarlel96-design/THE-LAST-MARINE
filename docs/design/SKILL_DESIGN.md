# WO-04 전술 스킬 계약

입력 → 해금 → 생존·조작 상태 → 상호 배제 → 자원 → 쿨타임 → 시전 → 중단 → 효과 → 소비 순서를 적용한다.
동일 프레임 Q/W 입력은 Q를 먼저 처리한다. 한 개의 스킬만 활성화한다.
실제 게임 일시 정지는 게임 프레임 진행을 멈춘다. 프로그램은 벽시계 타이머를 사용하지 않는다.

|스킬|조건|성공|중단|자원·쿨타임|
|---|---|---|---|---|
|Q/F7 방어 자세|해금·생존·정지·18초 경과|방어력 +2, 최대 6초|이동 명령·이동·사망·강제 이벤트|발동 시 18초, 중단해도 유지|
|W/F8 긴급 지혈|해금·생존·정지·키트·40초 경과|3초 후 최대 체력까지 25 회복|이동·위치 변화·누적 5 체력 피해·사망·강제 이벤트|완료 시 키트 1개와 40초, 중단은 소비 없음|
|E|M02 해금|4초 공격주기 감소 목표|이동·사망·종료|30초 목표, 구현 미확정|
|R|M03 해금·폭약·유효 지형|3초 설치 후 별도 지연 폭발|설치 중 이동·사망|60초 목표, 설치 완료 소비안 검토|

Q는 전용 Jim Raynor Marine 타입을 사용한다. 일반 Marine 동료의 방어력을 바꾸지 않는다.
타입 방어력은 원래 값을 저장하고 복구한다. 최고 능력치 성장 경로는 아직 확정하지 않았다.
SKILL_POC는 Q/W를 처음부터 연다. COLLAPSE_POC는 생존 구간 진입 후 W를 연다.
HUD는 5초마다 이름·키·쿨타임·키트를 표시한다. 거절 입력은 현재 차단 이유를 출력한다.
미출력 상태도 항상 보이는 최종 HUD는 별도 P1 작업이다.
초기 40 체력과 6 공격력은 원문 기획값이다. 시험 맵은 치료 시험을 위해 현재 체력을 30으로 시작한다.
