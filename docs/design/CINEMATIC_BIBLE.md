# 시네마틱 바이블

실제 공격받은 방어선이 무너진다. 병력은 교전과 명령에 반응해 이동한다.
폭발 원인은 공격받은 군수시설로 제시한다. 적 병력은 유한하게 사전 배치한다.
플레이어 앞의 즉시 생성은 사용하지 않는다. 증원에는 시야 검사가 필요하다.
카메라는 사건을 짧게 보여준 후 플레이어에게 돌아온다.
주인공을 연출 경로로 강제로 걷게 하지 않는다. 위험 신호와 대체 동선을 제공한다.
중요 NPC 사망 시 무전 호출부호와 다음 목표를 대체한다.
음향은 환경음·전장음·무전·강조음으로 구분한다. 무전 중 경쟁 효과음을 줄인다.
기본 게임 전투음은 엔진이 재생한다. 추가 폭발음은 직접 만든 합성 소리를 사용한다.
현 PoC에는 실제 음성 녹음과 믹싱을 넣지 않았다. 무전은 화면 텍스트다.
