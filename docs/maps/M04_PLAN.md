# M04 — 귀환한 망령: 신원 확인과 착륙지대 방어

상태: **제작안 / SCX 미구현**. Badlands 256×256, 8192×8192px. 목표 90~130분은 미검증이다. [좌표 규칙](README.md)을 적용한다.

## 1. 소유권과 지휘권

P1은 영웅만 조작한다. P3는 연합군 지휘부와 주둔군이다. P4는 고립된 연합군이다. P2/P6/P7은 서로 동맹인 저그다. P1/P3/P4는 양방향 동맹이다. 임시 지휘권 승인 시 지정 분대만 P3에서 P1으로 인계한다. 구조물 소유권은 유지한다. P12 표식은 군사시설 소유권과 구별한다.

## 5. 심사·인물·시네마틱

1. 접선 후 소속과 신원을 대조한다. 영웅의 장비와 소모품을 압수하지 않는다.
2. Review에서 필수 기록, 선택 기록, 본인 보고를 별도 줄로 표시한다. 필수 기록만으로 심사는 통과한다.
3. 베일 생존 기록은 북부 우회로와 후미 방어 증언을 연다. 사망 기록은 부대 기록의 추도 대사로 대신한다.
4. 렌 생존 기록은 동부 배수로 경고를 연다. 미구조 기록은 회수된 정비 문서만 증거로 인정한다.
5. 모로 구조 기록은 민간 생존자의 인명 명부를 연다. 이 증언은 군사 전과와 구분한다.
6. 실제 서쪽 접촉 후 지휘관 후송 사건을 시작한다. 부상자는 진료소까지 이동한 뒤 지휘권을 인계한다.
7. 분대 인계 후 CP2를 저장한다. 구조 성공 시 실제 생존자만 추가 인계한다.
8. 유한 공격대와 최종 방어를 처리한다. 살아 있는 P1 전투원과 지휘시설이 있어야 성공한다.
9. Exit에서 특별 임관 절차를 기록한다. M05의 대위급 권한은 계급 상승과 별개인 임시 보직이다.

도입 대사: “신원 번호는 확인했다. 이제 이 기록이 실제 전장에서 나온 것인지 대조한다.” 베일의 증언: “후미를 버리지 않았다. 살아 돌아온 사람의 이름을 확인해 보십시오.” 전공 부족 시: “추가 보고는 미확인으로 남긴다. 구조 신호와 핵심 시설 기록은 확인됐다.”

카메라는 사건 시작의 1회 소개 또는 사용자의 명시적 호출만 사용한다. Escape는 대사와 후송 이동 연출을 종료한다. 스킵은 적 격파, 구조, 전공이나 보상을 확정하지 않는다.

## 6. 체크포인트·계승·검증

CP0은 접선 전이다. CP1은 심사 완료와 공격 개시 전이다. CP2는 분대 인계 직후다. CP3는 최종 방어 전이다. 복원은 해당 CP의 분대 소유권, 생존 명부, 공격대 발급 비트, 시설 HP, 재고와 장비를 함께 재구성한다. 이미 받은 구조 보상은 다시 지급하지 않는다.

M03 입력 코드와 M04 출력 형식은 별도 버전 명세가 필요하다. M01 v1 코드를 덮어쓰지 않는다. 코드 UI가 없으면 고정 시작과 빌드 시 주입을 구별한다. M05 전달 데이터는 인물 상태, 심사 전공, 구조 인원, 지휘 평가, 지원 해금과 개인 장비다.

정적 인수 항목: 모든 연결로, 인계 대상 ID, 구조 전멸 분기, 두 구조 순서, CP별 소유권, 생성 50기 상한. 실게임 항목: 선택·집단 명령, 벙커/전차 사선, 증언 한국어 가독성, 병목과 부대 생존 난도. **모두 후속 제작·검증 대상**이다.
