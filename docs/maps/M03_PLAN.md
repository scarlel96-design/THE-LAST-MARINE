# M03 — 한 사람의 전쟁: 북부 군락 배치 설계

상태: **제작안 / SCX 미구현**. Badlands 256×256타일, 8192×8192px. 목표 100~140분은 플레이 테스트 전 기준이다. [공통 좌표 규칙](README.md)을 적용한다.

P1 영웅 1명으로 시작한다. P2는 정찰·전초 군락, P6는 연결시설·울트라, P7은 통신탑 급습대다. P2/P6/P7은 동맹이다. P12는 중립 시설과 표식이다. 생산, 확장 기지와 무한 적 생성은 사용하지 않는다.

## 5. 단계와 실패 처리

1. Survey를 확인한다. WatchPost 정보는 발견 경고와 정찰 기록을 연다.
2. DemoCache에서 R과 필수 폭약 1개를 확보한다. 이 폭약은 일반 소비와 분리한다.
3. TunnelWest에서 설치를 완료한다. 실패 또는 취소에는 폭약을 차감하지 않는다. 설치 후 대피 신호와 폭발을 순서대로 표시한다.
4. TunnelEast는 선택으로 둔다. 추가 폭약을 얻지 못해도 ForwardNest와 Hub를 공략할 수 있어야 한다.
5. Hub의 제어부와 보조부를 무력화한다. BossSafe를 저장한다. 보스는 추격·장애물 회피·정비 시간을 반복한다. 체력 증가만으로 난도를 올리지 않는다.
6. 울트라 격파 또는 서쪽·동쪽 차단 장치를 모두 작동시켜 격리한다. 서쪽 표식은 (176,95), 동쪽 표식은 (213,93)이다. 두 표식은 중립 테란 비콘(195)으로 배치한다. 각 접근 범위는 중심에서 2타일이다. 격파와 격리를 구분해 기록한다. 벙커 상실 후에도 격리 절차는 유지한다.
7. Relay 회로를 복구한다. 급습대를 막고 송신을 완료한다. Extraction에서 구조 응답과 전공 전송을 기록한다.

검증 게이트: 서·동 갱도 선택 조합, 폭약 0개 시작, 설치 중단, 울트라 고리 왕복, 차폐물 파괴 후 퇴로, 통신 급습 중 사망, 중복 생성 방지. M02 코드가 없으면 고정 시작 상태를 사용한다. 코드 해석과 인게임 적용은 분리 검증한다.
