## 좌표 표기

- 좌상단을 (0,0)으로 둔다. 오른쪽은 +x, 아래쪽은 +y다. 1타일은 32px다.
- 구역은 [좌, 상, 우, 하]로 표기한다. 우·하 값은 위치의 경계선 좌표다. 픽셀 경계는 각 값에 32를 곱한다.
- M01·M02는 SCX에 저장된 좌표를 사용한다. UNIT의 중심 타일 칸은 픽셀 좌표를 32로 나눈 뒤 내림한다.
- M03~M05 배치표의 좌표는 타일 그리드 교차점이다. 픽셀 중심은 (32x,32y)다. 별도 보정값이 없으면 +16px를 더하지 않는다.
- 대형 표기 n@x,y / c / dx,dy는 i가 0부터 n−1까지일 때 (x+(i%c)×dx, y+floor(i/c)×dy)다.
- 도색 사각형은 양 끝 타일을 포함한다. 전환 브러시가 추가한 경계 타일은 바깥으로 이어질 수 있다.
- MTXM CSV의 첫 행은 x 좌표다. 첫 열은 y 좌표다. 교차 셀은 SCX의 16비트 원시 타일 번호다. 브러시 ID와 구분한다.
- 유닛 종류와 소유자를 함께 확인한다. Unit 20은 주인공에게 사용하는 Jim Raynor (Marine) 원형이다.

## 제작과 인수

1. Dirt(2)를 기반으로 도색한다. High Dirt(3), Mud(4), Water(5), Grass(6), Asphalt(14), Rocky Ground(15)를 구별한다.
2. 지정된 고지 출입부를 전이 타일로 마감한다. 고지와 저지 사이를 양방향으로 검사한다.
3. 위치 경계와 건물 중심을 먼저 표시한다. 진행 표식과 건물 외곽을 겹치지 않게 한다.
4. 구조물과 장식 배치 후 통로 폭을 잰다. 표의 폭은 통행 가능한 연속 폭이다.
5. 시작 슬롯은 P1 한 명으로 고정한다. 연합군과 저그의 내부 동맹을 시작 트리거로 명시한다.
6. 출입 표식과 생성 지점에 공간을 남긴다. 시작 마커는 전투 유닛 수에서 제외한다.
7. 생성 전에 시야와 여유 공간을 확인한다. 실패 시 같은 적을 중복 생성하지 않는다.
8. 살아서 목적지에 도착한 구조 대상만 기록한다. 스킵과 복원에서 보상 플래그를 중복 적용하지 않는다.
9. 시작 후 클릭 선택, 이동, 가장자리 스크롤, 미니맵 이동을 검사한다. 조작 제한 시간을 별도로 기록한다.
10. 명세와 SCX를 대조한다. 충돌, 전투 거리, 카메라와 생성 성공은 실게임에서 확인한다.

기존 M01·M02 실측 문서는 기존 SCX와 빌드 기록을 대조했다. ASTRA M01은 이번 작업에서 별도로 빌드했다. ASTRA 소스 검사 41개와 SCX 재열기를 확인했다. 전체 실게임 검증은 **NOT RUN**이다. M03~M05는 **제작안 / SCX 미구현**이다.
