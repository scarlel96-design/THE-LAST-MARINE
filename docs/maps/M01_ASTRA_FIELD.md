## 2. 지형과 이동로

기반은 Dirt다. Asphalt는 생활·작전·산업 면과 도로를 구분한다.
Grass는 서쪽 수풀과 민간 시설 주변의 색조 차이를 만든다. 실제 수목 오브젝트는 없다.
Rocky Ground는 북부 마모 지대와 남부 수색 지역을 구분한다.
북부 공격 분리 고지 (79,55)와 동부 접근 분리 고지 (104,65)가 접근축 사이를 막는다.
서쪽 물골 (14,111), 동쪽 배수지 (172,88), 남쪽 범람지 (103,185)는 직접 횡단을 제한한다.
경계 전환은 scmJS의 지형 브러시가 생성한다. 최종 타일 번호는 실측표와 CSV를 따른다.
현재 고지는 접근을 제한하는 절벽이다. 오르내릴 수 있는 램프와 고지 사격 진지는 후속 미술 작업으로 남아 있다.

## 3. 소유권·시야·조작

P1은 영웅 1명과 시야 보조 개체 10개를 소유한다. 시작 위치 마커 1개는 별도다.
P3는 연합군 시설과 주둔군이다. P4는 모로와 주민 5명이다. P5는 구조 병력 3명이다.
P2/P6/P7/P8은 저그다. 시작 SCX에는 이 슬롯의 개체가 없다.
P12는 조사 비콘이다. 시설은 P3 소유이며 P12 비콘과 구분한다.
시작 트리거 8개가 양방향 동맹 행동 24개를 적용한다. 인간 플레이어는 P1 한 명이다.
시야 보조 개체는 주요 근무 구역에 분산한다. 붕괴 시 10개 모두 제거한다.
일반 진행은 자동 카메라 추적을 사용하지 않는다. J는 해병 선택과 화면 이동을 한 번 실행한다.
V는 작전사령부·정비·방어선을 4초 간격으로 보여준다. 마지막에는 해병 위치로 돌아온다.
Escape, 공격 개시, F9, 영웅 부재는 소개 카메라를 중단한다.
V를 사용하지 않으면 기지 소개를 직접 탐색한다. 실제 가장자리 스크롤과 클릭 선택은 NOT RUN이다.

생존 잔존대 HP는 배치 완료 후 65%로 설정한다. 적의 실게임 피해·이동 균형은 NOT RUN이다.
배치 함수는 P1/P3/P4/P5의 개체가 집결 중심에서 x·y 각 16타일 안에 있는지 검사한다.
주 집결지가 근접 범위에 들면 OuterReserve를 검사한다. 두 위치가 모두 노출되면 2초 후 다시 검사한다.
이 검사는 보수적인 거리 검사다. 엔진의 실제 안개 가시성 판독은 아니다.
실제 생성 수가 요청 수보다 적으면 미완성 부대를 제거한다.
이때 발급 플래그는 미발급 상태로 남는다. 재시도는 완료한 전투를 다시 생성하지 않는다.
부분 생성 처리에는 부대별 소유자·유닛 종류의 독점 사용이 전제된다.
유닛 한도와 실제 생성 실패의 강제 재현은 NOT RUN이다. 실패가 계속되면 사건이 대기한다.
전투 붕괴 구간의 Escape는 보상 없이 생존 상태를 구성하는 복구 수단이다.

## 7. 생존·장비·계승

Medical→Settlement→Relay→Supply→Exit가 필수 순서다.
각 필수 적 부대는 발급 완료와 제거를 모두 확인한다. 빈 부대만으로 목표가 완료되지 않는다.
선택 목표는 Archive, Salvage, Restricted, NorthRoute, SouthRoute다.
두 경로의 선택은 첫 조사로 확정한다. 시설과 보급품은 고유 비트로 중복 획득을 막는다.
Q/F7, W/F8, 자원 소비, 개량, 구조 결과와 계승 코드 계산은 기존 런타임을 재사용한다.
W는 정상 완료 시 키트 1개를 차감한다. 이동·피해 중단은 키트와 쿨타임을 소비하지 않는다.
E/R은 M01에서 잠긴다. 폭약 보유는 R 전투 효과의 구현을 뜻하지 않는다.
F9는 저장된 진행·재고·개량과 유효 영웅 위치를 복원한다. 전장의 완전한 시간 되감기는 아니다.
M02는 기존 v1 코드 해석기를 사용한다. 두 SCX 사이에 자동 공유 상태는 없다.
게임 내 코드 입력 UI는 미구현이다. 기존 빌드 도구의 `--code` 경로로 계승 시작본을 생성한다.
M03~M05의 인물 회수는 각 제작안에 기록했다. 해당 미션 SCX의 후속 대사 구현은 아직 없다.

## 8. 인수 기준과 남은 제작

실게임 인수는 클릭 선택, 화면 스크롤, 아군 오사 방지, V/Escape, 모든 구조 동선부터 확인한다.
다음으로 적 집결 노출, 전차·골리앗 교전, 추락 위치, 탄약고 두 경로를 검사한다.
마지막으로 W 중단·완료, F9 재고, 계승 코드와 M02 시작값을 대조한다.
보행 가능한 램프, 지형 장식, 수목, 파괴 잔해와 공성 모드 지원은 미완성이다.
카메라·한글·전투 템포·60~90분 목표 시간·몰입감은 NOT RUN이다.
네이티브 Q 충돌 경로는 격리 상태다. 네이티브 W와 상단 한글 자원 명칭은 미검증이다.
정적 PASS는 콘텐츠 완성 판정이 아니다. 현재 패키지 판정은 **PARTIAL**이다.
