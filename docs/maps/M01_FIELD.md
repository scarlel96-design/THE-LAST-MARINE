# M01 — 북부 능선 현장 명세

P1은 시작 마커와 영웅을 소유한다. P3는 UNIT 47개, P4는 주민 6명, P5는 구조 분대 3명을 소유한다. P12는 비콘 19개와 중립 시설 2개를 소유한다. 보급고 벽 20동은 실제 UNIT이며 스프라이트가 아니다.

시작 수정판의 네이티브 동맹 트리거 8개는 동맹 행동 24개를 실행한다. P1/P3/P4/P5와 P2/P6/P7/P8 내부 관계를 명시한다. 시작에 영웅을 한 번 선택한다. 시작, 붕괴, 스킵, F9에는 자동 화면 이동이 없다. J는 영웅을 선택하고 화면을 맞춘다.

적 72기는 초기 배치다. 북부 예비 52기와 생존 구간 잔존 20기로 나눈다. 반복 생성은 없다.

복원 위치: 0 Barracks, 1 Inner, 2 Shelter, 3 Medical, 4 Settlement, 5 Relay, 6 Supply. 사망 시 약 3초 후 Medical에 영웅을 생성하고 저장 위치로 옮긴다. F9는 현존 영웅을 이동한다. 저장한 진행, 보급, 장비와 체력을 적용한다. 모든 건물과 교전 상태를 원상복원하지 않는다.

Archive는 부품 1과 군사 정보, Salvage는 자재 10과 폭약 1을 준다. Restricted는 특수 장비와 부품 1을 준다. NorthRoute는 관측 경로를 남긴다. SouthRoute는 보급 경로와 자재 6을 남긴다. Relay 또는 Supply에서 소총은 자재 10, 전투복은 자재 12와 부품 1로 개량한다.

후속 확인 항목: 시작 아군 관계와 화면 이동, 구조 대상 이동, Crash 도착, 탄약고 피해 판정, F9 텍스트 잔류. 조작 점검용 SCX에는 본편 진행 트리거가 없다.
