# M02 — 고립된 전선 현장 명세

P1은 시작 마커와 영웅을 소유한다. P3는 배전기와 벙커 2동을 소유한다. P12는 시설·잔해 14개와 비콘 14개를 소유한다. P2 초기 시설은 부화장 1동이다. 초기 저그 이동 병력은 0기다. M01 시작 수정판의 네이티브 동맹 행동은 M02에 없다.

적 이동 병력은 임무 합계 43기다. 생성 위치는 트리거 위치 중심이다. 개별 유닛의 최종 픽셀은 엔진이 정한다. 기존 경로 감사에는 3×3 생성 여유 검사도 포함됐다.

| Phase | 위치·조건 | 현장 변화 |
| --- | --- | --- |
| 0–1 | Wreck G → Reactor G | 접속기·자재 8. 배전기 수리와 벙커 인계. 렌 구조 기록으로 부품 1. |
| 2–3 | 정찰대 제거 → Depot G → Garrison G | 키트 2·자재 12·부품 1과 E 해금. 방어 개시 전 선택 시설을 조사할 수 있다. |
| 4–5 | 1·2차 방어 | 감시 또는 계승 경고가 있으면 발동 대기 5초, 없으면 2초. 2차 종료 시 배전기 HP 상한을 최대 HP−400으로 낮춘다. 방진 조절기 보유 시 −200이다. |
| 6–8 | Relay G → Garrison G → 3차 방어 | 중계시설 수리, 배전기 최대 250 회복, 좌표 확보. 북문과 측면에서 동시에 공격한다. |
| 9–11 | NestLane/Nest 진입 → 병력·부화장 제거 → Nest G → Extraction G | 숙련 2단계와 M03 코드 확정. I로 기록을 보고 N으로 승리한다. |
| 90–91 | 배전기 파괴 또는 생성 오류 | N으로 패배한다. 생성 직후 적 수가 0인 경우를 검사한다. 일부만 생성된 경우까지 검출하지는 않는다. |

Mineral은 자재 14와 부품 1을 준다. Shelter는 기본 키트 1, 모로 구조 시 3을 준다. M01 주민 구조 기록이 있으면 자재 6을 추가한다. Drain은 Phase 3까지 자재 8, Watch는 Phase 3까지 부품 1이 필요하다. 개량은 전원이 들어온 Depot 또는 Motor에서 한다.

기본 시작: 자재 20, 부품 0, 키트 2, 폭약 0, 영웅 HP 45/55. 계승 시작의 HP는 55다. 계승판은 M01 코드를 사전에 해석해 별도 SCX로 만든다. M03 코드 코덱은 존재한다. M03 인게임 입력과 적용은 미구현이다.

F9 복원 위치: 0 Entry, 1 Reactor, 2 Garrison, 3 Relay, 4 Watch. 위치와 스킬 상태를 정리한다. 인벤토리와 전투 상태를 과거로 되감지 않는다. 도입 카메라는 Wreck으로 한 번 이동한다. 1초, G 또는 Escape로 영웅 화면으로 복귀한다.

후속 확인 항목: 초기 아군 관계, 벙커 인계, 배수로 분기, 중계기 복구, 지원병 생성 여유와 M03 코드 표시. R은 잠겨 있다.
