# 통합 개발 작업 기준

상태: 2026-11-03 통합 작업 패키지 지침 반영.
규칙 원본은 프로젝트 루트의 `AGENTS.md`다.
이 문서는 해당 규칙의 요약이다.
충돌하면 최신 사용자 지시와 `AGENTS.md`를 적용한다.

## 작업 패키지

1. 관련 소스, 설계, 이전 증거를 함께 읽는다.
2. 관련 기능을 하나의 작업 패키지로 구현한다.
3. 같은 패키지에서 오류를 수정한다.
4. 승인된 범위에서 자동 검사, 오류 수정, 재검증을 연속 진행한다.
5. 주요 기능 통합 후 실게임 시나리오를 한 번의 검증 묶음으로 검사한다.
6. 패키지 종료 시 결과를 한 번 보고한다.

작은 기능마다 작업을 종료하거나 다음 지시를 요구하지 않는다.
통과한 검사는 새 변경이나 실패 근거가 있을 때 다시 실행한다.
치명적인 위험은 즉시 검증한다.
현재 작업의 명시적 실행 금지는 이 예외보다 우선한다.
문서 전용 작업은 문서 변경과 규칙 충돌만 확인한다.
문서 전용 작업에서는 게임 실행, SCX 빌드, 기능 회귀 테스트를 실행하지 않는다.
일시적인 중단과 재개 상태는 최신 사용자 지시로 판단한다.

## 자율 판단

일반적인 버그 수정과 내부 구현 변경은 패키지 안에서 처리한다.
기존 기준 브랜치와 증거를 보존한다.
검증 중인 EUD 코드는 별도 시험 소스에 둔다.

다음 변경에는 사용자 판단이 필요하다.

- 핵심 게임플레이 변경.
- 제작 도구 또는 전체 아키텍처 교체.
- 별도 클라이언트 설치.
- 검증된 주요 기능 삭제 또는 축소.
- 비용 또는 외부 서비스 도입.
- 해결 경로가 없는 P0 문제.

## 증거와 판정

각 결과에 소스 해시와 실행 대상을 기록한다.
자동 검사 결과를 실게임 결과로 승격하지 않는다.
실행하지 않은 검사는 NOT RUN으로 기록한다.
현재 소스와 이전 SCX의 상태를 구분한다.
GO는 필수 요구사항의 실제 게임 검증 이후에만 사용한다.
중간 저장본은 최종 배포본으로 표시하지 않는다.

## 종료 보고

구현 기능, 변경 파일, Git 상태를 기록한다.
자동 검사와 실게임 결과를 기록한다.
미완성 항목과 남은 P0/P1을 기록한다.
다음 작업과 GO/PARTIAL/BLOCKED/NO-GO 판정을 기록한다.
문서 전용 작업은 문서 변경과 규칙 충돌 확인 결과만 보고한다.
