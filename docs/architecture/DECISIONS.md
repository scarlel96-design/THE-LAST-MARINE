# 임시 결정 기록

- D01: Phase 1은 scmJS 0.8.5와 고정 TrigScript 4.1.0으로 시험한다.
- D02: 전체 캠페인 구현은 Astra 승인 후 시작한다.
- D03: Q는 전용 해병 타입의 방어력을 일시 변경한다. 무적·Matrix 대안은 채택하지 않는다.
- D04: W는 정상 완료 시에만 자원과 쿨타임을 적용한다.
- D05: 지형·단위 배치·타이밍은 64×64 실험값이다. 최종 설계값이 아니다.
- D06: 미션 간 전달은 검증 전까지 A다. B가 권장 후보라는 원문 원칙을 유지한다.
- D07: 110초 복구는 RECOVERED다. 전투 성공으로 승격하지 않는다.
- D08: 월일과 임시 권한은 창작 설계값이다. 공식 확인과 구분한다.
