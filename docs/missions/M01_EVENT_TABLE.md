# WO-05 90초 붕괴 사건 표

64×64 Badlands 평지 시험 맵이다. 최종 M01 지형과 다르다.
P1은 주인공 타입 20 하나를 소유한다. P3은 동료와 시설을 소유한다.
P2는 저글링 20과 히드라 5를 사전 배치한다. 추가 생성은 없다.
Home은 중앙 대기 구역이다. Outer는 북부 벙커다. Relay는 남부 군수시설이다.
Safe는 남서쪽 보급 피난처다. Spawn은 북동쪽 적 준비 구역이다.

|M01.DEATH|장면 중|주인공 소실|효과 정리·RECOVERED, 3초 후 재생성|실패 전공 지급 없음|

스킵과 정상 종료는 같은 필수 파괴·재고·해금·위치 상태를 만든다.
사망 후 재생성 위치는 Safe다. 현재 체력 30, 키트 3, 쿨타임 0으로 복구한다.
자연 진행과 복구 종료는 서로 다른 상태로 기록한다.
현재 수송선 추락은 종료 시 파괴 상태만 보장한다. 비행·피격·추락 장면은 후속 작업이다.
