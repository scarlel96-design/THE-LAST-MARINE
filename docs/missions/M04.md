# M04 — 귀환한 망령

상태: 상세화 초안. 전체 미션 구현 NOT RUN.
크기 목표: 256×256. 목표 시간: 90~130분.

## 시작과 종료

시작 조건: M03 구조 신호 응답.
진행 순서: 신원 확인 → 물증 심사 → 습격 → 임시 지휘 → 분대 구조 → 방어 → 평가.
종료 조건: 착륙지대 생존과 현장 지휘 인정, 임관 절차.

## 구역과 전술

주요 구역: 정찰대 접촉점, 신원심사소, 착륙지대, 고립분대, 방어선.
선택 점수가 낮아도 스토리를 진행한다. 물증과 본인 보고를 분리한다.
각 구역은 진입, 목표 완료, 안전지대 확보의 체크포인트 후보를 가진다.
적 병력은 조우별 고정 예산을 가진다. 플레이어 체류 시간으로 무한 생성하지 않는다.
필수 목표에는 선택 자원과 독립된 최소 보급 경로를 둔다.

## 성장과 기록

해금: 분대 선택, 재집결, 집중 화력, 임시 지휘.
필수 전공: 착륙지대 방어; 지휘 평가.
선택 전공: 구조 인원; 검증된 추가 전공.
기록 ID는 `M04.RECORD.<목표>` 형식으로 고정한다.
목표 완료와 보상은 하나의 트랜잭션으로 적용한다.

## 검증

필수 경로, 선택 목표 생략, 자원 고갈, 반복 사망, 스킵, 경로 이탈을 각각 시험한다.
미션 시간과 전투 난이도는 실제 플레이로 측정한다.
지도 전체와 적 배치는 Astra 승인 후 제작한다.
