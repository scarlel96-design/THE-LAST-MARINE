# M05 — 전설의 지휘관

상태: 상세화 초안. 전체 미션 구현 NOT RUN.
크기 목표: 256×256. 목표 시간: 120~160분.

## 시작과 종료

시작 조건: 임관과 임시 작전 지휘권.
진행 순서: 교두보 → 구조 → 방어 안정화 → 생산시설 → 포병 → 증원로 차단 → 군락 공격 → 철수.
종료 조건: 주요 군락 무력화, 생존 병력 철수, 지휘 기록 확정.

## 구역과 전술

주요 구역: 전방 교두보, 고립부대, 군수·생산시설, 포병진지, 증원로, 최종 군락, 철수지.
연합 붕괴 통신 이후 부대 생존과 재편성 책임을 남긴다.
각 구역은 진입, 목표 완료, 안전지대 확보의 체크포인트 후보를 가진다.
적 병력은 조우별 고정 예산을 가진다. 플레이어 체류 시간으로 무한 생성하지 않는다.
필수 목표에는 선택 자원과 독립된 최소 보급 경로를 둔다.

## 성장과 기록

해금: 긴급 보급, 제한 포병, 지휘 통합.
필수 전공: 교두보 방어; 최종 작전 성공.
선택 전공: 생존 병력; 보급 효율.
기록 ID는 `M05.RECORD.<목표>` 형식으로 고정한다.
목표 완료와 보상은 하나의 트랜잭션으로 적용한다.

## 검증

필수 경로, 선택 목표 생략, 자원 고갈, 반복 사망, 스킵, 경로 이탈을 각각 시험한다.
미션 시간과 전투 난이도는 실제 플레이로 측정한다.
지도 전체와 적 배치는 Astra 승인 후 제작한다.
