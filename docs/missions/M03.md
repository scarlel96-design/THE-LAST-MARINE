# M03 — 한 사람의 전쟁

상태: 상세화 초안. 전체 미션 구현 NOT RUN.
크기 목표: 256×256. 목표 시간: 100~140분.

## 시작과 종료

시작 조건: M02 북부 접근로 확보.
진행 순서: 정찰·우회 → 폭약 → 증원로 차단 → 시설 파괴 → 울트라 1개체 → 통신탑.
종료 조건: 연결시설 파괴와 연합군 응답, 전공 전송.

## 구역과 전술

주요 구역: 북부 오염지대, 감시초소, 지하 이동로, 폭약시설, 전초 군락, 연결시설, 고출력 통신탑.
울트라는 장애물·방어시설·이동로를 요구한다. 체력만 늘리지 않는다.
각 구역은 진입, 목표 완료, 안전지대 확보의 체크포인트 후보를 가진다.
적 병력은 조우별 고정 예산을 가진다. 플레이어 체류 시간으로 무한 생성하지 않는다.
필수 목표에는 선택 자원과 독립된 최소 보급 경로를 둔다.

## 성장과 기록

해금: R, 최종 개인 무기, 강화복, 정예 단계.
필수 전공: 연결시설 파괴; 구조 신호.
선택 전공: 우회로; 보급 회수; 정예 적 격파.
기록 ID는 `M03.RECORD.<목표>` 형식으로 고정한다.
목표 완료와 보상은 하나의 트랜잭션으로 적용한다.

## 검증

필수 경로, 선택 목표 생략, 자원 고갈, 반복 사망, 스킵, 경로 이탈을 각각 시험한다.
미션 시간과 전투 난이도는 실제 플레이로 측정한다.
지도 전체와 적 배치는 Astra 승인 후 제작한다.
