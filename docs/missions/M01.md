# M01 — 마지막 생존자

상태: 상세화 초안. 전체 미션 구현 NOT RUN.
크기 목표: 192×192. 목표 시간: 60~90분.

## 시작과 종료

시작 조건: 정상 근무 중 침공 발생.
진행 순서: 경계 근무 → 최초 대응 → 후퇴 → 폭발 생존 → 의료시설 → 키트 → 정착지 → 통신 기록 → 보급시설.
종료 조건: 보급시설 확보와 다음 거점 확인.

## 구역과 전술

주요 구역: 막사·무기고, 중앙 통제, 외곽 초소, 정비구역, 의료시설, 정착지, 통신중계소, 보급시설.
폭발·사망·스킵 뒤 의식 회복 상태를 재구성한다.
각 구역은 진입, 목표 완료, 안전지대 확보의 체크포인트 후보를 가진다.
적 병력은 조우별 고정 예산을 가진다. 플레이어 체류 시간으로 무한 생성하지 않는다.
필수 목표에는 선택 자원과 독립된 최소 보급 경로를 둔다.

## 성장과 기록

해금: Q, W, 조사·수집.
필수 전공: 생존 확인; 통신중계소 조사.
선택 전공: 자료 회수; 군수품; 제한 구역.
기록 ID는 `M01.RECORD.<목표>` 형식으로 고정한다.
목표 완료와 보상은 하나의 트랜잭션으로 적용한다.

## 검증

필수 경로, 선택 목표 생략, 자원 고갈, 반복 사망, 스킵, 경로 이탈을 각각 시험한다.
미션 시간과 전투 난이도는 실제 플레이로 측정한다.
지도 전체와 적 배치는 Astra 승인 후 제작한다.
