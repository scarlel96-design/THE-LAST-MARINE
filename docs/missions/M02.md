# M02 — 고립된 전선

상태: WO-PROD-02 콘텐츠 구현. 소스·SCX 검사는 통합 제작 보고서를 참조한다. 실게임 NOT RUN.
크기 목표: 224×224. 목표 시간: 90~120분.

## 시작과 종료

시작 조건: M01 종료 또는 고정 최소 장비.
진행 순서: 군수 복구 → 보급 탐색 → 이동로 정찰 → 3회 방어 → 전초 반격.
종료 조건: 군수기지 생존과 북부 접근로 확보.

## 구역과 전술

주요 구역: 군수기지, 정비시설, 장갑차 집결지, 광물시설, 지하 이동로, 북부 감시시설, 전초 군락.
봉쇄는 공격 방향을 바꾼다. 감시는 경고 시점을 앞당긴다.
각 구역은 진입, 목표 완료, 안전지대 확보의 체크포인트 후보를 가진다.
적 병력은 조우별 고정 예산을 가진다. 플레이어 체류 시간으로 무한 생성하지 않는다.
필수 목표에는 선택 자원과 독립된 최소 보급 경로를 둔다.

## 성장과 기록

해금: E, 무기 2~3단계, 전투복, 감시·방어.
필수 전공: 군수기지 방어.
선택 전공: 이동로 봉쇄; 감시시설 복구; 추가 군수품.
기록 ID는 `M02.RECORD.<목표>` 형식으로 고정한다.
목표 완료와 보상은 하나의 트랜잭션으로 적용한다.

## 검증

필수 경로, 선택 목표 생략, 자원 고갈, 반복 사망, 스킵, 경로 이탈을 각각 시험한다.
미션 시간과 전투 난이도는 실제 플레이로 측정한다.
WO-PROD-02에 일반 시작 맵과 M01 계승 예제 맵을 제공한다.
검증된 M01 코드를 빌더에 전달해 별도 계승 SCX를 생성한다.
인게임 코드 입력 UI와 M03 본편은 미구현이다.
